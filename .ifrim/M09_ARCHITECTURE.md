### 3.1 A1 — model/effort binding (proposal → plan → confirmation → envelope → grant → dispatch)
`server/policy/model-binding.mjs` exports:
- `ROLE_PROVIDERS` and `normalizeBindingRequest({ role, provider, model, effort, profile })` → `{ ok, request, problem }` (pure; syntax only; refuses empty model for factory/envelope roles, `CLAUDE_REFUSED_MODELS`, `[1m]`, unknown effort).
- `resolveBinding({ role, provider, environment, requestedModel, requestedEffort, profile, providerState, now })` → `{ ok, binding, problem }` where `binding = { role, provider, environment, requestedModel, requestedEffort, profile, resolvedAlias, resolutionEvidence: { source: "model/list"|"claude-alias", listHash?, probedAt?, cliVersion?, family?, exactId? }, effort, effortSource, bindingHash }`.
  - Codex: `requestedModel` required and present in model/list for that state key (`codex` or `codex@wsl-runner`); effort ∈ model efforts; `listHash = hashCanonical(models.map(m => [m.id, m.efforts]))`.
  - Claude: `requestedModel` required, matches the shared reviewer allowlist (aliases `sonnet|opus|haiku` or dated `claude-(sonnet|opus|haiku)-…` ids), never refused models; `family` from alias; `cliVersion` from provider state.
- `bindingHash(binding)` (sha over canonical fields except evidence timestamps) and `compareAtDispatch(binding, plan, providerState)` → `null | { code: "MATERIAL_CHANGE", reasons[] }` (model differs, effort differs, Codex model gone from list or list hash changed in a way that removes it, Claude CLI version changed).
- `compareAtInit(binding, initModel)` → `null | reason` (Claude: init model must belong to `family` or equal `exactId`).

Rules:
- Factory missions (all entry points: packages, Autopilot, War Room drafts, Sales drafts, Lega proposals, manual `factory.prepare`) carry `limits.{writer,reviewer}{Model,Effort}`; a mission without both models is a DRAFT whose scope is incomplete (`view.scope = null`, problem listed; envelope `PLAN_INCOMPLETE`). No placeholder like „implicit (fix în plan)”.
- `startApproved` stores `factory_missions.bindings_json`; dispatch reads the binding from `bindings_json`, never from current `limits_json`; `request_json` gets `bindingHash`.
- Before any process: `runs.start` with a `binding` re-resolves and calls `compareAtDispatch`; a mismatch → gate refusal (category `gate`, pre-inference, not counted as an attempt, grant attempts not consumed).
- Claude adapter: `compareAtInit` at `system/init` → stop before the model if the init model is outside the bound family; `runs.mjs` stops silently backfilling `model` — record `plan_json.verified = { value, matched, at }`.
- Envelope `buildBody`: `missions[].bindings` and `models[mid]` from bindings (summary text, no placeholders); `summaryOf` shows models; `changedParts` labels include models. Grants derived from an envelope carry `binding_json`; `assertWithin`/`grants.problem` refuse a run whose binding hash differs (this also stops shadow reviews from consuming a grant bound to another model).
- `factory.resume` with `reviewerModel` under an ACTIVE envelope → refused with a clear message (a new proposal is needed); outside an envelope → recompute bindings + scope hash, emit `factory.model_override` with old/new.
- Manual `run.start` outside the factory: Codex with empty model → resolved NOW from model/list and recorded as requested (`modelSource: "account_default_pinned"`), verified at `thread/start`; Claude with empty model → refused (an explicit alias is required). Lega `propose_run` follows the same rule.
- Packages: `packages.mjs` structured `models = { writer: {provider:"codex", model:"gpt-6.1-sol", effort:"medium"}, reviewer: {provider:"claude", model:"sonnet", effort:"medium"} }`; texts derived from it; `preparePilot` passes them; `pilotPrepared` requires the mission limits to match.
- UI: PlanCard „Modele” row; FactoryPanel shows bound models; Owner.jsx package models from structured data.
- Tests T01 (`m09-model-binding.test.mjs`, ids `M09-MB-NN`): account default changed between plan and dispatch → refused pre-inference; empty requestedModel → PLAN_INCOMPLETE; retry/resume keeps binding; resume override under ACTIVE envelope refused; two stages with different models; ineligible alias (`fable`, `sonnet[1m]`, unknown Codex id, unsupported effort) refused at validation; UI–request conflict (manual run with another model cannot use the envelope grant); init mismatch stops before model; package B4 passes `sonnet` and fake-claude argv has `--model sonnet`.

### 5.5 compile.mjs + render.mjs + editors.mjs (EDIT)
- `compileRenderPlan({ ir, profile, assets: { [versionId]: { absPath, probe, sha256 } }, fonts: { [file]: absPath }, toolVersion, compileVersion })` — PURE. Returns `{ segments: [{ key, clipId, args, output, inputs }], final: { args, output: "out.partial.mp4", files: { "graph.txt", "<textfile>.txt", "captions.ass" } }, expectedDurationMs, canvas, fps }`. Segments normalize each primary clip (trim, speed, crop/fit/keyframes, color, fps, pix_fmt, canvas) and are cached by `key = sha256(compileVersion, toolVersion, asset sha, clip params, canvas, fps, profile)`. The final pass composes segments (xfade/concat), text (`drawtext` with `textfile=` relative paths and fonts copied into the job dir — no text inside the graph), captions (`subtitles=captions.ass:fontsdir=fonts`), audio (trim/delay/gain/fades/envelope/amix + loudness to the IR target), and encodes (draft: half resolution, `-preset ultrafast -crf 30`; final: `-preset medium -crf 18`, `yuv420p`, AAC 48 kHz, `+faststart`). All paths in args are relative to the job dir (Windows filter escaping is avoided). `-/filter_complex graph.txt`.
- `createRenderQueue({ db, bus, live, clock, paths, tools, assets, settings })` → `request({ editVersionId, profile, actor, idempotencyKey })` (INSERT OR IGNORE; duplicate returns the existing job), `cancel(jobId, actor)` (→ CANCEL_REQUESTED → kill → CANCELLED), `retry(jobId, actor)` (new job, cache reused), `tick()` (claims REQUESTED atomically when concurrency allows; `mediaPolicy.interactivePriority` defers renders while an AI run or Lega voice is active — via an injectable `isInteractiveBusy()`), `recover()` (CLAIMED/RUNNING/VALIDATING → INTERRUPTED; never auto-resumed), `get`, `list`.
  - Run: disk reserve check → compile → segments (cache hit or render to `.partial` → validate → cache) → final → validate (decodes, duration within ±1 frame + 50 ms, dims/fps/pix_fmt, audio present when expected) → promote to `renders/<jobId>.mp4` → `assets.registerDerivative` (category `render`) → DONE. Progress only through `live.publish({ type: "media.render.progress", … })` from measured `out_time_ms` / segment counts; persisted events only for transitions.
  - Failure codes: `DISK_RESERVE`, `DISK_FULL`, `TOOL_MISSING`, `INPUT_MISSING`, `INVALID_OUTPUT`, `TIMEOUT`, `CANCELLED`, `TOOL_FAILED`, `IR_INVALID`. Partial artifacts stay in the job dir with `journal.json` and are never served.
- `editors.mjs`: `EDITOR_ADAPTERS` registry with `inspectCapabilities()` per adapter — `ffmpeg` (RenderBackend, real), `premiere` (detects installation; NOT_INSTALLED here), `capcut` (detects installation/version; ASSISTED: `exportAssistedPack({ editVersionId })` → folder with cleared media, SRT, timeline table with timecodes, step list; CapCut project files are never edited), `otio` (`exportOtio(ir, assetsMap)` → OTIO JSON `Timeline.1` with ExternalReference), `edl` (`exportEdl(ir)` CMX3600 primary track), `explainEdit(ir)` (human-readable list: interval, asset, movement, caption, sound, reason).
